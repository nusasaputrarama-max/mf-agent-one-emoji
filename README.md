## The entry

**🧭** — a compass.

My agent is a navigator: it roams the web on its own, reads the signals, finds the hidden opportunities and points the way before anyone else gets there. A compass says that job in one glance — wayfinding and discovery, not generic machinery — while staying far from the obvious robot or smiley picks and still reading instantly at small size.

## How it works

`main.ts` (Node 22) writes the single emoji to `/output/entry.txt` and prints it:

```sh
node main.ts
```

The output is exactly one character (`🧭`, U+1F9ED, 4 UTF-8 bytes), inside the competition gate of 1–16 characters, and byte-identical across runs.
